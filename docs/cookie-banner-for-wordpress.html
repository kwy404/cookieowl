A free cookie banner for WordPress that blocks before consent

WordPress sites collect trackers from themes and plugins. One hook in functions.php puts cookieowl in front of all of them.

By Alexandre KohlerUpdated October 13, 20267 min read

#Why WordPress sites leak trackers

A typical WordPress site does not have one place where trackers live. The analytics plugin prints gtag.js, the theme adds a font service, a form plugin loads a captcha, and editors embed YouTube videos in posts. Each of them prints its scripts in wp_head or wp_footer, usually without asking anyone. A cookie banner plugin that only shows a notice leaves all of that running.

cookieowl solves it from the front of the queue. Printed as the very first thing in wp_head, it sets the Consent Mode defaults and starts watching the page, so every tracker printed after it is held until the visitor accepts its category.

#Install with one hook

Add this to the functions.php of a child theme, or save it as a file in wp-content/mu-plugins/ so a theme update never removes it. Priority 1 makes it print before the scripts that WordPress and plugins enqueue:

get_privacy_policy_url() returns the page you chose under Settings, Privacy, so the banner links to it automatically. With data-lang="auto" the banner follows the site language: a site set to Português do Brasil gets the LGPD text.

#A Cookie settings link and caching

Withdrawal must stay easy. cookieowl shows a small owl button on every page, and you can add a link to your footer menu: create a custom link with the URL #, then add data-cookieowl-open through a small filter, or place a Custom HTML block with <a href="#" data-cookieowl-open>Cookie settings</a> in a footer widget.

Caching and optimization plugins are compatible because nothing is rendered on the server. Two settings to check: exclude cookieowl.js from deferring, delaying and combining JavaScript, since it must run first and synchronously, and do not lazy load scripts marked text/plain, which some delay features rewrite.

Hoot says

Test with a private window after every plugin update. A new plugin version can add a tracker, and the Network panel is the quickest way to see it.

#Questions

Do I need a plugin to add cookieowl to WordPress?

No. A few lines in your child theme functions.php (or a small must use plugin) print the script tag at the top of the head. A header code plugin also works if it can print before other scripts.

Will it block Google Analytics added by Site Kit or another plugin?

With data-auto-block, cookieowl recognizes gtag.js, Tag Manager and the other known trackers by URL, even when a plugin prints them, as long as cookieowl is printed before them.

Does it work with page caching plugins?

Yes. The banner is rendered in the browser and the choice is a first party cookie, so cached pages are the same for everyone. Exclude the script from JavaScript minification and combining so it stays first.

What about embedded YouTube videos in posts?

Auto mode replaces YouTube and Vimeo iframes, including the ones the block editor embeds, with a click to load placeholder until marketing cookies are accepted.
