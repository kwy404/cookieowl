Why timing matters in Next.js

A Next.js page arrives as server rendered HTML, then the framework loads its JavaScript chunks and hydrates. Third party scripts added with next/script run at different moments depending on their strategy. If Google Analytics is added with the default afterInteractive strategy and your consent banner is a client component, the tracker can win the race: it runs as soon as the page is interactive, while the banner is still waiting for React.

The fix is to give the consent manager the earliest slot Next.js offers. The beforeInteractive strategy puts a script in the document head and runs it before any first party code. cookieowl sets the Consent Mode defaults and starts holding trackers there, and everything else follows.
